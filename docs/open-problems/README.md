# AI 角色扮演开发难题

[简体中文](README.md) | [English](README.en.md)

本目录公开整理电子爱在 AI 角色扮演与角色创作中需要重点研究的开发难题。这些课题不是已经确定的解决方案，也不代表对应功能已经完成。

## 公开课题

1. [Agent 的 Token 消耗与回复速度](token-cost-and-speed.md)

   Agent 一轮回复可能包含多次模型请求和工具调用。如何降低 Token 消耗、缩短等待时间，同时保留 Agent 能力，是目前最受关注的问题。

2. [Agent 回复界面与最终正文稳定性](agent-response-experience.md)

   Agent 不只有一段最终回复，还拥有工具调用、执行进度和错误信息组成的时间线。怎样清楚展示这一过程，并稳定地从模型输出中分离最终扮演正文，直接影响日常使用体验。

3. [聊天记录与工具结果的长期记忆](conversation-history.md)

   完整保存工具结果会造成上下文膨胀，全部丢弃又可能让 Agent 重复检索。怎样在长期剧情连贯、信息新鲜度和 Token 成本之间取得平衡，仍需要继续研究。

## 当前阶段

电子爱目前仍在快速完成 Agent 运行时、角色创作、状态管理和前端能力等地基建设。上述问题已经进入公开课题清单；待基础链路稳定后，将结合真实对话指标和实验结果继续深入研究。
