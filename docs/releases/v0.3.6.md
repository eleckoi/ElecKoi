# ElecKoi v0.3.6

## 对话与角色卡

- 角色对话可以在聊天显示设置中隐藏顶部视图栏，打开其他视图后仍可返回聊天。
- 调整 Agent 对话的头像、名字、消息操作和生成提示。点击角色头像可以进入角色卡编辑。
- 修复编辑长助手消息时正文被压成窄列的问题。用户消息的编辑框和按钮重新与右侧对齐。
- 角色卡导入和导出增加处理进度提示。

## 创作预设与 EJS

- 创作预设的常驻提示词可直接选择插入位置。旧「默认位置」条目移到「系统指令」，保留正文与启用状态。
- AI 选读的 EJS 正文在模型点名读取时才渲染，关键词条目先匹配再渲染。关闭触发规则的条目仍可通过 `getwi` 引用。
- 修复个别 EJS 条目失败时影响整轮对话的问题，其他条目继续按顺序发送。
- 修复 Gemini 使用 OpenAI Chat Completions 兼容接口时，连续工具调用可能丢失思维签名的问题。

## Windows

- 修复冷启动时壁纸插件的开机动画偶尔提前结束，以及壁纸下标题栏出现色差和分隔的问题。
- 独立编辑窗口加载失败时可在本窗口查看错误，主窗口保留自己的重试入口。
- 角色与预设侧栏的「新建」按钮及详情页的返回按钮跟随浅色和深色主题。
