# ElecKoi v0.2.14

## 开场白与全局设定库

- 角色编辑器新增独立的「开场白」页面，集中编辑多个不同开场白、默认开场及各自的变量版本绑定和初始变量。开场白独立于设定库版本保存。
- 设定库通过「角色／全局」切换。全局库可导入其他角色的设定库，或导入并转换酒馆世界书；导入后复用正常的条目、文件夹和编辑操作，支持启停与删除。
- 全局设定库独立于角色设定库版本；角色设定库的管理、切换和导出继续按角色归属处理。
- AI 创作能力对齐独立开场白及变量绑定，支持完整读取、批量修改与大结果续读；误传开场白版本字段时明确报错。

## 正则 EJS 与前端卡

- EJS 显示模板统一在正则替换内容中编辑，支持异步计算、变量读取和预览；显示替换保留原始消息，按选定范围处理显示或模型请求。
- 前端兼容代码集中在独立兼容层，通过 ElecKoi SDK 接入消息网页；补齐通用变量读取和变更通知。
- 修复正则生成的前端因内联模块而持续隐藏，以及前端变量无法及时加载、刷新通知缺失的问题。
- 创作能力说明明确正则 EJS 的编辑位置和预览参数，预览会等待计算完成，失败时保留已保存的规则。

## 角色与预设编辑

- 角色管理增加复制角色卡，单击可进入编辑；右键菜单提供常用角色操作。
- 设定库、正则和脚本统一使用角色在前、全局在后的切换方式，工具栏操作保持集中。
- 统一新建按钮和开场白操作布局，修复预设选中边缘被遮挡、侧边分隔线断开、关闭整库后文字状态未同步等问题。
- 修复右键菜单点击外部无法关闭，以及右键打开菜单时误触发条目或预设编辑器的问题。
- 聊天正文保持 DSH 默认渲染规则。

## 运行与工具

- DSH 依赖对齐至 0.2.1-rc.3，更新对应插件组合和客户端接口，角色与创作预设停用内置提醒工具。
- DeepSeek 联网配置统一接入官方设置入口，保留当前搜索、抓取和完整结果读取能力。
- 统一错误码与失败提示，完善跨消息关键词匹配、工具结果继承鉴权和完整设定读取。
- 设定、变量和聊天运行上下文由 Host 内存按会话管理，减少运行中的文件中转。
- 修复旧数据库升级前误要求新版表的问题，沿既有流程升级并保留有效数据。
