# ElecKoi v0.2.20

本次为预发布版本，提供 Windows x64、Android ARM64 标准版与兼容版。

## DSH 版本升级

- DSH 从 **0.2.1-rc.5 升级至 0.2.2-rc.1**，Host、Client、SDK、模型适配器和插件组合统一跟随同一版本；Cordis 同步升级至 4.1.0，pi-ai 升级至 1.3.0。
- 跟进新版官方桌面原生能力、应用退出清理及 Windows 安装器，保留 ElecKoi 的品牌、更新源和数据目录。
- 头像上方增加更新入口，更新信息使用独立窗口展示。
- 创作工作区侧栏接入官方「自动化任务」，使用对应的任务与工作流工具分组；插件与更多入口保留在最左侧导航。

## 创作工作室

- 创作预设的提示词分为常驻、Agent 必读和选读，Agent 可直接发现、搜索及读取当前工作室的提示词，无需先选择角色。
- 设定正文支持按原文片段局部替换，修改一段内容不再需要重新提交整篇正文；找不到原文或匹配不唯一时明确返回原因。
- 创作工具的处理过程可直接查看能力目录、正文、配置字段、原文与新文、校验结果和版本回执；必读提示词回执、选读正文与续读片段分别展示，保留查看原始调用的入口。
- 修复首次重新生成报历史加载错误、删除后残留正文，以及重新生成时权限变灰、统计消失和短暂闪现新对话首页的问题；编辑期间保留输入草稿与原对话布局。
- 手机新对话补齐吉祥物、欢迎语、工作区与创作预设选择；发送后沿用原输入框进入对话，保留草稿。
- 工作室侧栏按创作会话范围统一筛选分组、搜索和行操作，排除角色扮演会话；切回原生工作区仍使用其原目录。
- 更换首页睡眠鲸鱼娘素材，以渐隐边缘衔接背景；移除工作室右上角重复的新建按钮。

## 模型与输入

- 角色聊天与工作室统一使用官方模型菜单，模型和推理等级选中即生效，保留键盘操作与手机窄屏收纳。
- 参数区增加「取消／保存」：编辑只修改草稿，点击保存后才写入；停输、失焦和关闭菜单不再自动提交。直接关闭或保存失败后可继续编辑原草稿。
- 参数区支持温度、Top P、上下文窗口、自动压缩阈值和最大输出，并可声明图片输入能力与自定义推理档位；上下文窗口与最大输出可恢复目录继承，推理选项按模型实际声明显示。
- PC 外侧模型入口恢复模型图标，菜单内当前模型与选项保持文字；提供商分组保留自己的图标，手机继续使用原收纳入口。
- 修复手机输入按钮过大、正文重复留白和参数菜单拥挤的问题，较长参数可在原菜单内滚动查看。
- 修复 Android 角色扮演与工作室的三横线输入菜单展开后被压成窄条、文字被裁切的问题，菜单按屏幕可用宽度展开。

## 角色聊天与显示

- 预设常驻系统指令在官方系统说明之前组装，实际请求与轨迹同步显示，重新生成和预览不再重复追加。
- 聊天列表按实际消息活动排序，重新生成也会立即更新最近聊天时间，保留置顶顺序。
- 修复删除回复并保留用户输入后被误记为异常中断的问题，以及部分处理过程行导致楼层顺序颠倒的问题。
- 设定与变量的修改过程提供可读明细，区分成功、拒绝、失败及未变化；长详情保留完整内容，修复手机滚动时反复跳动的问题。
- 「字号与字体」统一使用官方正文、代码和终端设置，展开一次即可看到全部六项；角色聊天与工作室共用字体配置。
- 角色头像旁增加查看头像与编辑角色卡的快捷菜单，修正菜单深色边缘和缩放时侧栏加号偏心的问题。

## 界面、语言与桌面

- 接入官方八语言运行时，并补齐 ElecKoi 自有页面、菜单、提示、手机界面和插件说明；语言入口位于聊天显示卡片列表末尾，切换语言保留草稿、输入焦点、自定义名称和会话内容。
- 主窗口默认尺寸调整为 1480 × 970，会话侧栏默认宽度为 280px，保留原有拖动、折叠和窄窗口布局。
- 恢复角色前端编辑器中的预览、导入和更多操作图标，图标跟随当前主题；修正开场白工具栏图标按钮被内边距撑宽的问题。
- 修复浏览器及远程插件代理加载产品网页资源时的白屏问题，窗口控件按实际桌面能力显示。
- Windows 应用菜单补齐开发者工具入口，以及 Ctrl+Shift+I、F12 快捷键。
- 修复 Windows 打包遗漏部分去重依赖、导致安装包内 Host 无法启动的问题。

## 问题报告与运行诊断

- 社区菜单提供「报告问题」；主窗口、独立聊天和手机的运行错误弹窗也可直接进入报告预览，当前错误码自动填入可编辑的补充说明。
- 报告可预览全文、选择是否附带日志尾、复制或导出文件；长正文独立滚动，不再挤占备注和选项区域。
- 内置正式飞书表单填写入口，打开前先尝试复制报告全文，由用户检查并提交；邮件与直接发送通道按配置显示。报告过长时明确提示截断或摘要，剪贴板失败、浏览器打开失败也分别说明。
- 桌面保留未送出的报告草稿，可在下次启动后重新送出或丢弃；打开表单后仍保留草稿，确认提交后由用户清理。
- 改进异常退出判定，较早发生的异常不会因后续几次正常启动而被误判为正常；异常结束时默认附带日志尾，用户仍可取消。
- 补齐本机路径、凭据、邮箱及电话号码等敏感字段的隐藏处理，覆盖嵌套详情、正文和日志；报告由用户主动发出。
- Android 标准版与兼容版共用「运行诊断」和报告入口，记录启动、页面异常、卡住与恢复等信息；内存记录改为仅在吃紧或明显增长时保存，减少重复记录。

## Android 修复与安装兼容

- 标准版与兼容版沿用原正式应用签名，并补齐 **V1、V2、V3** 三种签名；两版使用相同应用身份，可按原有方式覆盖安装。
- 修复首次创建默认工作区时因系统缺少 `xdg-user-dir` 而失败的问题，使用应用自己的私有工作区目录，已登记工作区继续按原标识和路径恢复。
- 补齐随包自动配图插件的可用项，默认保持关闭，由用户自行启用。
- 修复「更多插件」页面出现两个返回按钮的问题，返回概览后恢复原标题栏。
- 更新 Android 内置运行资源，固定资源下载快照，修复旧下载地址失效及组合模板读取不匹配的问题。

## 升级说明

- 创作预设改用文本常驻、必读和选读。旧关键词提示词转为选读；旧 EJS 和引用保留源码并停用。此转换同时覆盖创作预设的已保存版本，角色扮演预设保留原有能力。
- 创作预设导出格式更新为 v3，旧 v1／v2 文件在导入时转换为当前格式。
- 现有角色、聊天与工作区资料保留。已有历史中的真实异常中断记录不会被改写为正常结束。
