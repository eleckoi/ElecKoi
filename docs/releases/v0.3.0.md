# ElecKoi v0.3.0

## 角色资产库与完整卡打包

- 角色编辑器新增资产库，支持图片、视频、音频和模型的导入、预览、搜索、筛选、复制、重命名、下载与删除。
- 混合文件夹支持新建、改名、移动及递归删除；网格与列表可切换，移动或改名保持素材引用不变。桌面可直接打开素材所在文件夹。
- 完整角色卡的 PNG、ZIP、JSON 以及角色复制均保留资产、目录、空文件夹与前端文件；前端包继续保留包内相对路径。
- 角色页面与楼层界面共用固定资产引用，完善动态媒体加载、文件回收和导入失败恢复。

## 创作工作室

- AI 可明确读取和修改共享全局与当前角色的设定、正则、脚本及配置版本，包含全局库管理、角色自定义位置、脚本按钮和导出选项。
- 接入资产管理与独立前端项目操作，支持工作区文件导入、文件夹移动、项目文件修改、选择和导出。
- 角色、资产、楼层界面和独立项目采用按需技能与参考文档，具体参数通过实时能力目录查询。
- 明确常规创作保留聊天楼层，正则生成 HTML、正文 HTML 和后台脚本／按钮面板可以协作；独立项目用于整体自定义内容区交互。
- 修复部分更新重置未提交配置、正则保存改变启用组合，以及请求期间切换角色可能误写新目标的问题。

## 编辑器与窗口

- 统一角色卡与预设编辑器的目录标题、文档标题、列表间距和手机搜索样式，减少读取占位和草稿恢复闪动。
- 编辑器窗口跟随主窗口当前尺寸、最大化状态和所在显示器；调整基础资料留白与浅色资产层次。
- 修复资产菜单被侧栏裁切，以及手机错误弹窗落底、复制按钮拥挤等问题。

## 富消息与退出修复

- 修复带有视口高度限制的图片在富消息中缩成细线的问题；保留内容自动测高，正确处理图片延迟加载、动态样式、窗口缩放及内容增减。
- 修复 Windows 更新退出时，迟到的网页日志回调访问已销毁原生对象而报错的问题。
