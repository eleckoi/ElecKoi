# ElecKoi v0.3.3

## 预设与编辑器

- 预设目录批量读取摘要和条目数量，避免进入或新建预设时加载全部正文；完整编辑器与文本编辑组件按需加载。
- 修复预设基本资料初次打开时更新记录突然下移的问题，统一卡片宽度与滚动条位置。
- 编辑器开关、复选框、内容图标及新建／保存按钮统一适配深浅主题；修复资产按钮文字和添加更新图标显示。
- 预设更新记录使用与界面一致的中性色，主题风格入口改用调色盘图标。
- 设定库导出等待文件保存完成，取消不提示成功，失败可在当前管理窗口重试。

## 对话与窗口

- 开场白翻页箭头贴合正文末行，短文和空文避开头像与楼层，页码保持紧凑。
- 修复删除当前历史时角色范围被提前清空、历史列表短暂显示空态的问题，删除失败会在当前窗口提示。
- 修正角色会话的前台工作区持有方式，以及角色对话、创作工作室的右栏显示衔接。
- Windows 右栏及宽度手柄避让顶部拖动区域，恢复关闭入口的正常点击。
- 修复弹窗标题栏标记的生命周期，原生窗口按钮随深浅和透明主题同步，侧栏品牌区域不再误拖动窗口。
- 酒馆风格浅色气泡默认使用 #FAFAFA，气泡与底板默认不透明度为 100%；Agent AI 浅色气泡使用 #F5F5F5 并取消描边，已保存的自定义值继续生效。
