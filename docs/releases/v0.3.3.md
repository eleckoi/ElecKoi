# ElecKoi v0.3.3

## 对话与创作工作室

- 角色对话、创作工作室和独立窗口接入官方页面与会话容器，保留现有导航、各页管理侧栏、头像和工具过程等产品设计。
- 修复长工具参数持续输出时反复重画、界面与计时刷新迟滞的问题。
- 修复长对话及流式输出中，输入菜单、权限和统计浮层偏离触发按钮的问题。
- 角色轨迹改用官方完整视图，恢复输入区的递归与队列功能。
- 整理会话编辑与激活流程，恢复工作区原有初始化、监听和归档清理；修复启动时错误创建默认会话的问题。
- 修正角色会话的前台工作区持有方式，以及角色对话、创作工作室的右栏显示衔接。
- 修复删除当前历史时角色范围被提前清空、历史列表短暂显示空态的问题，删除失败会在当前窗口提示。

## 文件读取与创作工具

- 上传、拖入和本机路径引用接通官方 `read`／`read_image`，默认关闭可选工作区工具时仍有基础读取能力；文件修改和命令继续由原工具开关控制。
- 撤除重复的自制附件读取工具，已有生成预设在加载时接回官方读取组合。图片仍取决于模型图片能力，二进制文档需要相应解析能力。
- 修复角色对话开启“创作能力”后工具未实际装配的问题，支持发现、搜索角色及指定目标；绑定角色继续作为快捷定位方式。
- 预设和对话工具列表展示默认启用的基础读取工具；创作预设隐藏不适用的剧情变量、角色设定库和角色扮演计划。
- 工具管理窗口去掉彩色图标底块，统一为中性图标与边框行。

## 预设与编辑器

- 预设目录批量读取摘要和条目数量，避免进入或新建预设时加载全部正文；完整编辑器与文本编辑组件按需加载。
- 修复预设基本资料初次打开时更新记录突然下移的问题，统一卡片宽度与滚动条位置。
- 常规确认、命名、分组、删除、导入、资产及报告弹窗统一使用官方组件；保存离开确认固定为“取消／不保存／保存”。
- 编辑器开关、复选框、内容图标及新建／保存按钮统一适配深浅主题；修复资产按钮文字和添加更新图标显示。
- 添加、新建入口统一使用官方按钮，角色卡和预设目录按钮恢复与保存按钮一致的紧凑尺寸。
- 空正文开场白可保留、切换及排序，首位与主开场白同步；翻页箭头贴合正文末行，短文和空文避开头像与楼层，页码保持紧凑。
- 新建设定和变量不再自动全选名称；变量运行配置、变量及变量组的图标和文字起点统一，组展开操作保留。
- 预设更新记录使用与界面一致的中性色，主题风格入口改用调色盘图标。
- 设定库导出等待文件保存完成，取消不提示成功，失败可在当前管理窗口重试。
- 修复手机聊天记录的删除确认框被记录面板遮挡的问题。

## 背景与消息显示

- 聊天背景改由独立插件承载，修复设置预览正常、正式聊天却不显示的问题；保留立绘、自定义图片、共享背景和原有材质设置。
- 修复开启消息底板后无法拖动官方横向宽度条的问题，阅读宽度和保存恢复正常。
- 酒馆风格气泡首条贴合内容顶部，默认消息净距为 5px、上下内距为 10px，并支持单独调整气泡间距。
- 窄屏消息底板铺满内容区，宽屏保持居中；气泡和底板缺省颜色跟随官方主题，保留用户显式自定义颜色。
- 酒馆风格浅色气泡默认使用 #FAFAFA，气泡与底板默认不透明度为 100%；Agent AI 浅色气泡使用 #F5F5F5 并取消描边，已保存的自定义值继续生效。
- 整理“酒馆风格”“Agent 气泡显示”等设置名称与顺序，修复实时预览内容贴边。

## Windows 窗口

- Windows 右栏及宽度手柄避让顶部拖动区域，恢复关闭入口的正常点击。
- 修复弹窗标题栏标记的生命周期，原生窗口按钮随深浅和透明主题同步，侧栏品牌区域不再误拖动窗口。

## Android

- 手机输入框修复空草稿挂载失败，返回会话与打开加号菜单时保留输入选区，避免额外请求键盘；菜单点击和发送沿官方流程。
- 发送图片时接续已有本地预览，正式资源读取完成前保持显示，减少图片闪空。
- 预设目录支持用途切换、分组横滑与排序，显示作者、模型和使用状态；共用搜索页可直接打开指定预设。
- 角色详情集中显示竖封面、作者和简介，操作固定在底部；统一聊天顶栏分割线、编辑器卡片与全局设定库外观。
- 启动页使用应用 Logo、气泡与像素星光加载条，按实际准备阶段累计进度，界面就绪后撤场。
