# ElecKoi v0.3.3

## 预设与编辑器

- 预设目录按需读取摘要和条目数量，避免进入目录或新建时加载全部正文；完整编辑器与文本编辑组件按需加载。
- 修复预设基本资料初次打开时更新记录突然下移的问题，统一 PC 卡片宽度和滚动条位置。
- 手机预设目录采用用途切换、分组横滑与展开面板，支持分组排序；卡片显示作者、模型及使用状态。
- 手机预设搜索接入共用搜索页，可按名称或作者定位并打开指定预设。
- 编辑器开关、复选框、内容图标及新建／保存按钮统一适配深浅主题；修复资产按钮文字和添加更新图标显示。

## 对话与界面

- 修正角色会话的前台工作区持有方式，以及角色对话、创作工作室的右栏显示衔接。
- Windows 右栏避让顶部拖动区域，修复弹窗标题栏标记生命周期、原生窗口按钮主题及侧栏品牌区域误拖窗。
- 手机聊天与创作工作室恢复顶栏分割线和主题底色，侧栏恢复既定展开动效与前景布局。
- 手机角色详情保留竖封面，集中显示角色名、作者和简介，进入对话与编辑操作固定在底部。
- 酒馆风格浅色气泡默认使用 #FAFAFA，气泡与底板默认不透明度为 100%；Agent AI 浅色气泡使用 #F5F5F5 并取消描边，已保存的自定义值继续生效。
- 手机角色与预设菜单使用连续圆角轮廓，消除尖角和面板的拼接感。

## Android 启动

- 启动页使用应用 Logo、气泡和蓝紫像素星光加载条，统一普通启动与首次安装的等待界面。
- 加载条按实际复制、解压、环境校验及界面就绪阶段累计进度，跨阶段不归零，界面绘制完成后撤场。
