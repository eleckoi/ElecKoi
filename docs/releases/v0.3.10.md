**群聊多角色对话迎来更新。一个回复里可以让多位角色接续发言，子代理的发言也会实时出现在主对话。**

## 群聊与角色对话

- 多位角色的头像和正文按发言顺序流式显示。主代理能收到子代理已经显示的发言，继续推进剧情，避免重复发出同一段正文。
- 多角色回复可继续编辑或删除，旧聊天可以正常回看。从子代理发言创建分支时，沿用对应的原用户输入。
- 自动配图仍可随角色发言提交。角色布局和 Agent 布局都能在发言完成后按显示正则渲染分镜图。给模型的提示词规则独立处理，聊天原文继续保留。
- 长对话按实际发送给模型的内容判断何时压缩，包括附件、本轮工具结果和工具定义。压缩保留正在进行的一轮，摘要会读到已确认的多角色和子代理发言，旧工具过程仍可在轨迹查看。

## Windows 更新与工作区

- Windows 应用内下载完整安装包时，断网或重启后可以接着下载。安装包仍会校验完整性和签名。
- 插件页面入口放在创作工作区侧栏。取消固定后，在同一栏的「更多」里可以打开或重新固定。「自动化任务」固定在这列，最左侧的「插件」可打开插件中心。
- 工作区侧栏底部的插件区域可滚动。模型配置列表和插件中心列表新增插件扩展入口，可沿用搜索、选择和原有添加流程。

## 从旧版升级时一并获得的修复

- 修复编辑已有预设时，即使共享提示词没有改动，也可能保存失败的问题。旧预设的内置扮演计划自动采用新版发言方式，自定义步骤继续保留。
- 修复带历史图片的聊天在编辑、回退或分支后可能无法恢复的问题。导入聊天和读取旧预设时也保留图片移除记录，修复关闭会话时的保存冲突。
- 修复角色卡改名后聊天仍显示旧名称，以及 PC 详情页被过长的登场角色名撑宽的问题。开场白列表展示摘要，搜索和编辑仍使用全文。
- PC 的角色卡与预设正则、脚本编辑器顶部可导入 JSON 和打开版本管理。角色资产批量复制、移动、删除和导出减少重复读取。角色卡与设定库的创作教程也已更新。
- 变量目录的同级条目对齐。安卓创作工作室的轨迹底部为输入框留出空间，并补齐搜索、角色封面和设定库等界面的翻译。
