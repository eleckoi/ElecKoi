**务必更新，回复工具逻辑大调整，用旧版可能会导致聊天记录在之后的新版不显示，请尽快更新至当前版本。**

## 角色回复工具重做

- 原来模型先调用工具选择角色，再另发一条带角色标签的正文。现在 `eleckoi_roleplay_reply` 一次接收发言角色和完整正文。单人填写一个角色字段，多人按发言顺序填写各自的字段。正文从工具参数流直接显示，提交成功后结束本轮。
- 工具会列出当前可发言的角色，角色名单与可填写的字段同步。角色预设的发言指令提前，设定库和变量工具也会提示模型按同一套方式提交回复。
- 子代理调用回复工具时，发言实时出现在主对话。已经显示的正文会通知主代理，便于它继续推进。子代理只返回分析或资料时，由主代理提交角色正文。
- 自动配图的占位符写进角色正文，分镜随同一次工具调用提交。角色布局与 Agent 布局都会在正文完成后应用显示正则并渲染分镜图。给模型的正则规则独立生效，存档保留原文。

## 本次重打补上的修复

- **长聊天生成更轻。** 新片段只更新当前轮或对应的子代理发言，已完成消息的正文、工具过程、正则结果、楼层和消息索引会复用。翻页、编辑、删除和回退会按变化后的记录刷新。
- **旧聊天和开场白继续接得上。** 会话历史可读取旧版「先选角、后发文」的记录，也能从新版工具调用恢复正文。列表预览、编辑、删除和从子代理发言创建分支继续使用对应的会话记录。
- **模型读到的历史更清楚。** 单角色的开场白和回复直接提供正文。多角色的发言者另起一行，原来的台词、动作和叙述继续保留。继续聊天、请求预览和摘要复用同一份历史整理结果。
- **自动压缩按实际请求判断。** 附件、本轮工具结果和工具定义都计入。压缩保护正在进行的一轮，生成摘要前还原已确认的角色正文和子代理发言。旧工具过程仍可在轨迹查看。
- **生成状态绑定当前聊天。** 等待模型响应时，输入框上方会显示状态。已有过程时，可点击同一位置查看详情。切换会话时，状态会跟随当前聊天。
- **PC 角色卡和预设详情调整。** 关闭按钮移到弹窗内详情栏右侧，角色卡与作者信息同排，预设与摘要同排。点击遮罩或按 Escape 也可以关闭。
- **设定库和变量树统一展开操作。** 文件夹和变量组可用图标按钮展开或折叠。鼠标悬停、键盘聚焦时会显示箭头，手机编辑器也有足够的点击高度。
- **安卓会话存储打包校验已同步。** 标准版和兼容版都装入更新后的会话存储文件，保留原有的安卓写入保护。

## Windows 更新、工作区与前几轮修复

- Windows 应用内下载完整安装包时，断网或重启后可以接着下载。完成后仍校验安装包完整性和签名。
- 插件页面入口在创作工作区侧栏，取消固定后可从同栏「更多」打开或重新固定。自动化任务固定在这列，最左侧「插件」打开插件中心。工作区底部插件区域可滚动，模型配置和插件中心列表也新增了插件扩展入口。
- 修复了编辑已有预设时，共享提示词没改动也可能无法保存的问题。旧预设只会自动更新内置扮演计划的默认收尾，自定义步骤继续保留。
- 修复带历史图片的聊天在编辑、回退、分支、导入或读取旧预设后可能无法恢复的问题。会话关停会等待正在进行的存储操作，避免把正常关闭当成保存失败。
- 修复角色卡改名后聊天仍显示旧名称，以及 PC 详情被过长的登场角色名撑宽。开场白列表只展示摘要，搜索和编辑可以读取全文。
- PC 角色卡和预设的正则、脚本编辑器顶部可直接导入 JSON、打开版本管理。角色资产批量复制、移动、删除和导出减少重复读取。角色卡和设定库的创作教程也已补齐。
- 安卓创作工作室的轨迹底部为输入框留出空间。补齐手机搜索、角色封面和设定库等界面的翻译。
