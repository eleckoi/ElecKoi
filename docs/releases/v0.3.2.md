# ElecKoi v0.3.2

## 对话与创作工作室

- 角色对话、创作工作室和独立窗口接入官方页面与会话容器，保留现有导航、各页管理侧栏、头像和工具过程等产品设计。
- 修复长工具参数持续输出时反复重画、界面与计时刷新迟滞的问题。
- 修复长对话及流式输出中，输入菜单、权限和统计浮层偏离触发按钮的问题。
- 角色轨迹改用官方完整视图，恢复输入区的递归与队列功能。
- 整理会话编辑与激活流程，恢复工作区原有初始化、监听和归档清理。

## 文件读取与创作工具

- 上传、拖入和本机路径引用接通官方 `read`／`read_image`，默认关闭可选工作区工具时仍有基础读取能力；文件修改和命令继续由原工具开关控制。
- 撤除重复的自制附件读取工具，已有生成预设在加载时接回官方读取组合。图片仍取决于模型图片能力，二进制文档需要相应解析能力。
- 修复角色对话开启“创作能力”后工具未实际装配的问题，支持发现、搜索角色及指定目标；绑定角色继续作为快捷定位方式。
- 预设和对话工具列表展示默认启用的基础读取工具；创作预设隐藏不适用的剧情变量、角色设定库和角色扮演计划。
- 工具管理窗口去掉彩色图标底块，统一为中性图标与边框行。

## 背景与消息显示

- 聊天背景改由独立插件承载，修复设置预览正常、正式聊天却不显示的问题；保留立绘、自定义图片、共享背景和原有材质设置。
- 修复开启消息底板后无法拖动官方横向宽度条的问题，阅读宽度和保存恢复正常。
- 酒馆风格气泡首条贴合内容顶部，默认消息净距为 5px、上下内距为 10px，并支持单独调整气泡间距。
- 窄屏消息底板铺满内容区，宽屏保持居中；气泡和底板缺省颜色跟随官方主题，保留用户显式自定义颜色。
- 整理“酒馆风格”“Agent 气泡显示”等设置名称与顺序，修复实时预览内容贴边。

## 编辑器与交互

- 常规确认、命名、分组、删除、导入、资产及报告弹窗统一使用官方组件；保存离开确认固定为“取消／不保存／保存”。
- 添加、新建入口统一使用官方按钮，角色卡和预设目录按钮恢复与保存按钮一致的紧凑尺寸。
- 空正文开场白可保留、切换及排序，首位与主开场白同步；翻页控件独立排列。
- 新建设定和变量不再自动全选名称；变量运行配置、变量及变量组的图标和文字起点统一，组展开操作保留。
