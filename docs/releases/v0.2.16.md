# ElecKoi v0.2.16

## 预设与插件

- 预设工具按来源分组管理，支持添加、移除和随预设导出插件工具引用。缺少插件时提醒，仍可继续聊天。
- 角色自动配图拆为独立插件，默认关闭。
- 升级至 DSH 0.2.1-rc.5，完善高版本数据库的识别和错误提示。

## 聊天与编辑

- 桌面增加应用、编辑菜单，检查更新使用 ElecKoi 自身的更新源。
- 模型配置使用分组浮层，支持模型与参数统一保存，并展示插件提供的模型名称和标签。
- 全局设定库支持重命名；导入没有内置书名的酒馆世界书时保留原文件名。
- 修复手机编辑器工具栏换行、范围切换过大、开场白按钮拉长及模型保存按钮配色问题；开场白和全局设定库统一使用官方玻璃底材。

## Android 后台与通知

- 后台回复成功完成后显示角色头像、名字和回复文本；在应用内使用时不提醒。
- 修复重新生成后漏发完成通知的问题，移除启动和持续运行通知。
- 后台运行设置提供电池优化豁免、悬浮窗保活开关和权限入口。开启并授权后，退到后台挂载保活窗口，返回前台移除。
