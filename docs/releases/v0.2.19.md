# ElecKoi v0.2.19

## 变量初值修复

- 修复变量配置包含动态组时，默认值已经修改，但新建对话仍使用旧值的严重问题。例如将“第一日”改成“第一天”后，新对话现在会正确使用修改后的值。
- 保存时同步生成开局数据，保留动态组中已填写的具体内容；升级时修复已保存的不一致初值，已有聊天的变量、进度和历史保持不变。
- 开场白只使用明确绑定的变量版本；未绑定时不启用变量，移除额外的开场白独立初值来源。
- 玩家通过角色前端填写的数据继续只属于当前聊天，新建对话从作者配置开始。

## 创作工作室

- 工作室直接在主窗口打开，使用 DSH 官方工作区浏览、权限选择和会话菜单。
- 增加空对话首页，切换工作区后保留未发送的文字及附件草稿。
- 补齐默认创作预设的工作区、任务、多代理、联网与插件发现工具，修复部分内置工具的中文信息显示。
- 工作区会话菜单增加删除入口；角色聊天仍通过聊天记录管理。
- 修复排队消息与输入框的对齐和间距。

## 聊天显示与导航

- 角色扮演布局增加对话底板、消息气泡及各自的模糊、色调、不透明度设置，默认关闭，可在“聊天显示 → 布局独有风格”启用。
- 修复切换背景模式后自定义图片丢失的问题，保留已选图片及其参数。
- 调整角色消息间距，修复背景覆盖聊天头部及输入区渐变的问题。
- 统一 PC 顶栏与原生窗口按钮，调整导航图标间距和选中动画。
- 侧栏使用覆盖式滚动条，分组标题支持吸顶，展开或收起时保持列表宽度稳定。

## 联网搜索

- 修复 DeepSeek 搜索卡片只跳转配置、无法真正选中的问题。
- 增加独立的“前往官方插件配置”按钮。选择 DeepSeek 默认使用 Messages 搜索，关闭新版 Web 搜索 API 也能保存选择；已启用新版 API 的配置继续保留。
