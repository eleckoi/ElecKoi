# ElecKoi v0.3.1

## 角色管理与作者资料

- PC 角色库新增默认、最近／最早导入、最近编辑和名称排序；整理角色与预设卡片、搜索栏、分组右键菜单和滚动条。
- 安卓角色库支持横滑分组、展开管理、长按调整分组顺序及批量移动角色；删除分组后保留角色并归入未分组。
- 角色基础资料新增独立的作者名称、头像和卡片预览，列表展示原作者；PNG／ZIP 导出、素材包往返和角色复制保留作者资料及资源。
- 角色卡导出统一为 PNG／ZIP，继续支持已有 JSON 卡片导入和预设 JSON 导出。

## 导入配置与创作工作室

- 修复完整卡、预设和命名版本导入时脚本、正则总开关被关闭或遗漏的问题，按文件原有配置保留启停状态。
- 修复前端明确未选择时仍自动选第一项的问题，保留实际选择的项目或空选择。
- 修复单条旧会话异常导致整个工作室不可用的问题，失败会话和引用文件保留，其他会话仍可正常使用。
- 修复删除模型提供商后工作室或角色对话打不开、无法换模型的问题；保留原会话与历史，换成可用模型后可继续。重新生成在改动记录前检查模型。
- 修复外网离线状态影响本机 Host 结果更新的问题，减少工具已完成但界面仍停滞的情况。
- 更新内置默认创作预设的完整提示词和工具配置。曾修改过内置默认创作预设的内容也会在这次升级中替换；自建预设保留，完成替换后的再次编辑会保留。
- 建卡默认放在未分组，不再把新建分类或询问分组作为前置步骤。

## 界面与运行诊断

- 修复安卓输入菜单跑到页面顶部的问题，角色对话与工作室菜单恢复按钮上方的官方定位。
- 分支设定和预设提示词统一正文／设置编辑方式，整理手机搜索、目录和底部操作区，移除旧编辑器及多余侧栏滚动。
- 错误弹窗和成功通知采用官方组件，统一返回、焦点和通知停留行为；搜索清空按钮仅在非空且聚焦时显示。
- 补全 PC 与安卓的 Host 原始诊断。PC 报告保留读取范围内的原始日志、异常原因、聚合明细和长堆栈，重开前及轮转文件中的记录也能随报告导出，不再只剩短摘要。
- 安卓渲染进程退出后的重试会重建页面，继续使用仍存活的 Host。

## 运行组件与 Windows 更新

- 升级至 DSH 0.2.2-rc.3，接入新版子代理、账号认证、模型和联网配置；恢复官方子代理调度及认证后的后台 Cookie 清理。
- PC 更新说明支持宽版 Markdown 阅读，标题与操作区固定，长说明独立滚动；侧栏底部显示下载百分比及更新状态。
- Windows 安装过程使用官方独立状态提示窗，更新操作增加忙碌保护；修复插件页刷新、添加按钮换行后被裁切的问题。
