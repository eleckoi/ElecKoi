# ElecKoi v0.2.18

## 处理过程展示重构

- 使用 **DSH 官方组件重构角色对话的处理过程展示**，统一呈现思考、工具调用和历史过程。
- 工具详情可直接跳转至官方轨迹查看，修复思考重复显示的问题，移除已不适用的旧显示选项。
- 改进设定库和剧情变量的工具结果展示，支持目录浏览、结果内搜索和完整正文阅读，并补齐必读标记与分类统计。

## 子代理问题修复

- 修复角色对话调用子代理后，主对话提前结束、后续重复回复的问题。
- 修复子代理相关的历史轮次识别与重新生成异常，编辑或删除对话时同步停止相关子任务。
- 修复创作工作室子代理的会话归属和预设管理问题，完善通过官方侧栏查看子对话的体验。

## 设置界面优化

- 重新整理设置页布局、留白、分组和卡片样式，统一使用官方界面材质。
- 完善布局、外观和侧栏角色图的预览展示。
- 调整用户资料与头像管理入口，姓名和头像修改后自动保存。

## 其他更新

- 完善插件工作区，新增「进入工作区界面」入口，并为插件创建补充 ElecKoi 开发参考文档。
- 分离工作区、角色扮演和创作工作室的会话列表，修复导航与侧栏切换异常。
- 优化安卓工作区和创作工作室的移动端布局，补齐「更多」菜单及工作区入口，改善处理过程面板的开合流畅度。
- 重整角色前端管理界面，支持完整 HTML／ZIP 包导入、文件浏览和预览。
- 开场白页面新增搜索，移除启用开关；主开场白留空时，新对话不显示开场白。
- 统一角色对话使用当前全局预设，修复旧会话引用历史配置及重新生成后的恢复问题。
- 修复更新弹窗中 Markdown 格式无法正常显示的问题。
