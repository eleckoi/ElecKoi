# ElecKoi v0.2.18

## 新增与调整

- 「更多」增加「进入工作区界面」，插件创建随包提供 ElecKoi 开发参考；工作区保留固定主导航，并与角色扮演、创作工作室的会话列表分开。
- 角色聊天的处理过程可查看思考、工具调用和历史过程，工具详情直接定位轨迹；设定库和剧情变量支持结果目录、搜索与完整正文阅读。
- 角色前端支持完整 HTML／ZIP 包导入、文件浏览和预览，相关操作集中在单行工具栏。
- 开场白页面增加官方样式的搜索框，移除启用开关；主开场白留空时，新对话不显示开场白。
- 调整设置页面的布局和预览，恢复输入菜单中的「新建对话」，权限菜单统一为「仅可查看」「工作区内修改」「完全权限」。

## 修复

- 修复工作区会话被角色发送检查拦截，以及返回角色对话后右侧栏无法正常展开的问题。
- 修复子任务结束后重复回复、历史唤醒影响轮次和重新生成，以及工作室管理预设与子会话绑定的问题。
- 修复处理过程重复显示思考、设定搜索缺少必读标记和统计的问题。
- 修复角色前端在独立区域中无法铺满、布局占位和 WebAssembly 资源类型问题。
- 修复旧角色会话继续引用历史运行预设的问题，统一使用当前全局预设并保留原历史。
- 修复更新弹窗把 Markdown 标题、列表与下载链接直接显示为原始文本的问题。
