# ElecKoi v0.3.4

## 对话与创作工作室

- 创作工作室在用户消息的复制按钮旁增加修改入口，可以原位修改输入，保留附件与后续回复。
- 修复侧栏“创建你的插件”只填入草稿、没有跳转到创作工作室的问题。
- 独立角色前端可以接管聊天正文和输入区，完整展示作者设计的交互界面，保留历史与轨迹入口。
- 创作能力查询默认提供准确参数和调用说明；参数错误附纠错指引，只读查询可省略空参数对象。
- 设定写入明确区分正文与读取提示，遗漏正文时提供需补齐的字段，方便继续原操作。
- 修复正则中的角色、用户与消息变量宏在匹配、预览和正式显示中的展开及转义不一致问题。
- 自动配图、媒体资源和局部配置读取失败时，保留仍可工作的正文、作者页面及会话，并提供对应错误信息。
- 修复会话改写成功后，旧图片清理失败被误报为整次修改失败的问题。

## EJS 与引用设定

- 设定模板使用正式 EJS 引擎，修复省略分号、行注释、转义标签及空白控制等标准写法解析失败的问题。
- 补齐完整 Lodash、聊天文字读取和变量副本能力，修复 `_.cloneDeep` 等函数缺失及历史相关模板未取得聊天内容的问题。
- EJS 引用设定增加与选读设定一致的“文字／EJS”切换，切换保留原正文。
- 动态引用支持多层计算，共用当前聊天的变量与历史上下文；文字引用保持原样，循环引用会显示完整路径链。
- 创作工具同步支持角色与共享设定库的动态引用创建、格式切换和正文修改，并补充递归引用示例。

## 编辑器与界面

- 优化角色头像、封面和目录加载，大量角色或会话的列表使用按需呈现，减少重复图片解码与界面卡顿。
- 图片裁剪改进旋转按钮、图标和缩放条布局，支持双指放大缩小，抬起一指后可继续拖动。
- 修复前端包选择、更多菜单及资产库菜单偏离触发按钮、出现在屏幕角落的问题。
- 模型列表及相关弹窗修复内容区域手势无法正常滚动的问题。
- 角色设定库版本管理下拉框统一使用现有菜单样式。
- 脚本面板减少外层标题、厚边和大块留白，将更多空间交给作者界面。
- 聊天“更多／返回”恢复原有菜单切换与焦点行为。

## Windows 窗口与更新

- 修复 Windows 安装包误含其他平台依赖、预编译文件和编译中间产物导致体积增大的问题。
- 全窗口作者界面上方的原生窗口按钮使用透明底色，并按页面背景调整按钮颜色，退出后恢复应用主题。
- 修复隐藏下载进度后，完成安装确认与进度入口衔接不正确的问题。
