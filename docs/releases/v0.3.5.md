# ElecKoi v0.3.5

## 角色、预设与编辑器

- Windows 角色与预设首页使用卡片目录。可以按组查看内容，打开详情后再进入编辑器。
- 统一手机和桌面的设定库、开场白、变量、脚本及正则编辑入口。导入设定时可以搜索来源、选择版本，再挑选要并入的条目。
- 优化桌面页面间的切换动画，并在系统开启减少动态效果时缩短或跳过动画。
- 修复窄屏编辑器标题、底部操作和弹窗滚动问题，让长内容和保存按钮都能正常访问。

## 设定、对话与工具

- 合并普通设定与引用设定的编辑入口。正文支持文字和 EJS，触发规则统一配置。升级时会转换旧引用设定，旧文件仍可导入。
- 调整角色聊天中的工具结果，方便展开查看及复制内容，并改进工具变更后会话内容的刷新。
- 网页搜索沿用 DSH 自动选择。DeepSeek 官方 API Key 和账号模型使用服务端搜索，其他模型使用 DeepSeek Search API。已经保存的手动选择仍然生效。
- 将 Windows 和 Android 共用的 DSH 运行基础升级至 0.2.2-rc.5。
