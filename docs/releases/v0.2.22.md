# ElecKoi v0.2.22

## 角色卡与预设编辑

- PC 预设主页面集中展示资料、使用说明和更新记录，编辑时打开独立窗口，可在对话旁持续编辑。
- 设定、变量、正则、脚本、开场白和预设提示词使用统一工作台，保留搜索、选择、草稿和统一保存。
- 长正文、说明与代码接入共用编辑视口，支持沉浸编辑和完整保存，减少长文本带来的页面卡顿。
- 修复预设反复进入短暂空白、新建后迟迟不显示、侧栏删除缺少确认，以及位置管理和展开字段布局问题。

## 手机编辑与处理过程

- 角色卡和预设编辑器适配手机布局，使用可收缩侧栏，点击条目进入独立详情，保留顶部统一保存和底部触屏操作栏。
- 优化关键词、匹配规则、位置排序和工具列表排版，修复管理位置无法滚动、正文切换异常及空列表显示问题。
- 多选操作补回取消入口；修复处理过程弹窗打开卡顿，保留原思考、工具调用和结果内容。

## 对话快捷菜单

- 输入区菜单集中提供工具、切换预设、新建、删除和重新生成；角色扮演另提供全局设定库。
- 变量、上下文和脚本入口归入「更多」，脚本按钮标明角色、预设或全局来源。
- 保留菜单定位、键盘操作和焦点返回，修复多余滚动及切换会话后的菜单残留。

## 会话模型与生成参数

- 每个聊天保留自己的模型、推理程度和生成参数，新建聊天使用最近的默认模型。
- 修复恢复聊天、逐步请求和工作室重新组装时，全局默认覆盖当前聊天选择的问题。
- 参数按会话及模型分别保存，切换模型清除前一模型独有的采样控制，回退消息保留当前选择。
- 当前聊天引用失效模型配置时明确提示错误，可重新选择有效模型。

## 聊天导入与重新生成

- 导入聊天后按当前角色建立关联，保留正式会话历史与有效消息身份。
- 修复跨角色导入后首次重新生成因缺少本机配置而报错，以及导入根会话无法修改、删除或回退的问题。
- 修复角色并发切换、空模型绑定和旧订阅干扰当前聊天的问题。
- 完善删除和重新生成期间的消息投影、页面状态与生成统计，减少旧消息残留和空页面闪现。

## 桌面交互与图标

- 恢复启动发现更新后的提示，以及下载进度关闭、重新打开和安装确认流程。
- 独立预设窗口的网页搜索、子智能体配置入口可打开主窗口对应配置，保留原编辑草稿。
- 修复角色卡、预设管理器窗口按钮与内容画布底色不一致的问题。
- 统一应用图标，侧栏使用平滑缩放，Windows 窗口使用多尺寸 ICO；无图片的模型提供商文字标识改为居中的圆角方框。
