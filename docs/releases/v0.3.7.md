# ElecKoi v0.3.7

## 角色对话

- 多位角色可以在同一轮中接续发言。对话按角色流式显示正文、头像和配图，开场白也能编排多位角色的发言。
- 子代理选定发言角色后，主对话会显示该角色并实时接收正文。发言完成后可以在主对话里重新查看、编辑或删除，也可以从该条发言创建分支。
- 生成过程可以从输入框上方打开，置底按钮恢复到原来的间距。

## 角色卡、预设与设定库

- 角色卡可管理登场角色、简介和各自的头像。旧角色卡升级时会自动补上登场角色，保留原有头像和聊天。
- 调整角色卡与预设的详情和编辑入口，桌面编辑窗口会跟随发起窗口所在的屏幕打开。
- 统一设定、变量、正则与脚本的目录和搜索。长篇设定可进入独立正文编辑，自定义插入位置的选中状态更清楚。
