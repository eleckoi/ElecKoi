# ADR 0037：统一编辑器与完整配置版本

状态：已采纳

日期：2026-10-13

## 决定

正则、脚本及手机变量／设定库共用紧凑的搜索与操作工具栏，顺序为搜索、新建、多选、管理、保存。保存与其他操作集中在左侧。

2026-11-11，PC 设定库按确认稿改为大导航、目录、编辑区三列。目录与编辑区各有圆角表面，中间窄间隙支持调整目录宽度；搜索、新建、多选和管理归目录，角色／全局位于目录顶部，版本选择位于底部。正文默认直接编辑，基本信息与读取／触发／插入集中于设置视图。唯一保存入口按用户最新要求放在目录「新建」之后，仍统一保存角色与共享全局的待保存修改；切换条目、范围或版本只更新草稿。两端共用原业务模型、版本及保存服务，不新增数据边界。

PC 变量编辑器按确认稿使用同样的两块独立圆角面板，目录默认 480px，搜索和目录操作属于目录，唯一统一保存位于「新建」之后，空选中与多选仍可保存；设定库也采用相同顺序与默认宽度。单变量的基本信息、说明和更新规则在同一表单中，变量组保留对象内容，固定运行配置保留初始状态与校验规则。目录与文档只负责呈现，草稿、版本、剪切粘贴、结构应用和保存仍由原面板及模型维护；手机保留原单页装配。

多选在主界面呈现勾选框、全选与选中数量，执行复制和删除。固定条目不可删除或复制。管理弹窗复用锁定 DSH 的 Modal、Button 与 Menu，管理命名版本及导入导出，重命名使用既有 NotePencil 编辑图标。脚本保留分类文件夹，打开源码目录属于管理操作。

角色编辑入口只有共享全局与角色配置；预设入口只有同一共享全局与预设配置。共享全局不会因入口变化复制成两份。保存包含源码配置和命名版本的同一事务，未修改的其他库不随本次操作写回；跨窗口冲突保留草稿并拒绝覆盖。

正则、脚本的分组标题开关批量设置整个库与全部条目的启停状态，包含搜索隐藏的条目以及脚本文件夹和其中的脚本。开启全部启用，关闭全部停用；单个条目仍可独立修改。保存后，运行时只处理整体与条目均启用的配置，脚本还要求所属文件夹启用。条目或其所属组关闭时名称置灰，仍可编辑。正则的整体状态与规则源码一起进入命名版本，当前启用组合同步更新；共享全局状态在两个编辑入口读取同一份数据。

## 版本与数据

设定库和变量沿用既有完整版本。正则、脚本新增完整命名版本；旧正则启用组合仍独立保留，它只代表启停集合，不能当作包含表达式和替换源码的版本。

数据库 v11 → v12 单次原子增加 display_template_libraries、editor_library_versions 和 regex_libraries，共享全局模板直接采用当前结构，不拆分未发布的中间步骤。正则整体状态按 scope、ownerId 归属，没有已保存状态时启用，保留原来的条目状态；已知未发布 v12 缺少该表的库先校验结构再原子补齐，旧正则命名版本补 enabled=true。版本按 kind、scope、ownerId 唯一归属，持有版本名称、稳定编号、当前版本及修改版本。迁移不修改现有聊天、角色、预设、正则或脚本正文。尚未保存版本的库直接以当前有效配置展示默认版本；读取不写数据库。

脚本源码与资源继续属于文件系统。命名版本保存为摘要寻址的不可变 JSON 归档，SQLite 仅保存归档引用；归档包含脚本树、源码、库设置和 base64 资源。切换版本沿用脚本文件事务恢复源码与资源。外部修改通过实际 workspace 内容摘要拒绝覆盖。未引用归档在下一次版本事务或启动前清理，最多延迟一个事务，清理错误不伪装成保存失败后的成功。

删除最后一个版本创建空白默认版本，保持编辑器有明确当前版本。导入使用 eleckoi.editor-library-version / version=1 的类型化 JSON，含 kind、name、content；脚本与正则导入库默认停用。此格式与整张角色卡、整份预设导出不同，整包仍沿用当前活跃配置合同。

## 公开能力

Host 使用正式 Typert Remote readEditorLibraryVersions / saveEditorLibraries，Client 通过 ctx.remote 调用。作者 SDK 的 editorVersions.read/save 使用独立权限，角色绑定本页角色，预设绑定当前扮演预设；创作工具按明确编辑角色或 presetId 操作。配置正文和当前命名版本必须一致，版本编号、归属、资源摘要与重复身份均严格校验。
