# ADR 0022：模型配置的发现与采样参数

## 状态

已采纳，2026-10-02。

## 决定

- 保留 ElecKoi 模型页面，所有配置通过 DSH settings/profile/credentials 保存。
- 通用提供商尚未添加模型时，允许单独保存地址、协议、请求头和密钥。未完成的 profile 只保存在 `eleckoi-client-models` 设置条目的 `draftProfile` 中，密钥仍由 credentials 持有，不向 pi-ai 注册空模型路由。手动添加或读取模型后，通过官方设置校验写入 `llm-pi-ai`，同时移除待配置 profile；移除最后一个模型时先保留待配置 profile，再撤下运行路由。读取模型不是保存配置的前置条件。
- 密钥小眼睛通过产品 Typert Remote 按当前配置引用调用官方 credentials.resolve；明文仅保存在正在展示的输入区域内，隐藏或切换配置时清除，不进入配置快照或保存草稿。
- 聊天沿用官方 Session 的 running、promptError 与 lastAgentError；Agent 运行失败通过独立控制事件终止产品等待并保留原始错误。发送与重新生成失败时先解除忙碌状态并报告错误，再刷新历史，不能让刷新阻塞错误呈现。
- DeepSeek Messages 读取锁定版本专用适配器的正式模型目录；通用协议使用同版本 pi-ai discovery。草稿发现通过 Typert Remote 在临时 Cordis Context 中装配官方适配器，使用当前地址、请求头和一次性凭据，不修改持久设置。
- Generate Content 在同版本 `dsh-llm-pi-ai` 的协议工厂表登记 pi-ai 已有的 `googleGenerativeAIApi`，配置校验和正式聊天共用这条原生请求路径。模型发现按 Google `models.list` 合同使用 `x-goog-api-key`、`models/{model}`、`supportedGenerationMethods` 与 `nextPageToken`；只采用明确支持 `generateContent` 的模型，保留地址中的部署前缀和版本路径，并将分页总响应限制在已有的 4 MiB 边界内。模型列表不用于推导推理档位，不切换为其他协议；配置地址须包含站点要求的版本路径，与 pi-ai 的生成请求一致。
- 现有 Top P 补丁已覆盖通用协议。专用 Messages 的序列化器补充同一 GenerateOptions 字段到 `top_p` 的最小映射；不另造适配器。官方扩展注册只提供 Session 身份而不提供完整 GenerateOptions，不能据此猜测某次请求的采样参数。
- 推理能力仅来自正式目录或既有显式 profile，模型发现结果不推导推理档位。已确认能力和用户参数在发现、保存、重开时保留。
- 保留当前系统代理行为，专用适配器未公开的请求头不能静默保存为已生效。
- 接口下拉框只表示四种通信格式，专用 DeepSeek 适配器归属不作为第五种格式。清除或删除配置通过 settings 与 credentials 执行；共享凭据仍被其他配置使用时保留，专用配置清空后恢复提供商默认设置，不卸载官方适配器。
- 聊天弹窗保留模型与参数页，参数仍写入同一模型配置。新聊天的选择通过生成的 Remote 合同交给 Host，并通过正式 SessionController 记录；已有聊天引用已删除的配置时，将有效替代选择写回同一个 Session。
- Host 启动时从生成的预设声明目录登记实际存在的定义，再允许 SessionController 冷恢复；不能仅在 agents.resume 包装器中登记，因为官方 Controller 在调用它之前已经解析预设。Session 快照可能在预设声明删除后仍存在，不能把目录内每个快照引用作为整个 Host 的启动依赖；缺失预设只在访问对应 Session 时报告原始错误。
- Host 发布 ready 前检查角色列表、聊天列表与角色会话等必需服务，缺失时明确列出服务名，不能在业务服务缺失时继续宣告启动完成。

## 独立配置与内置目录

2026-10-14：桌面列表按 Provider ID 显示独立配置，取消提供商内的配置版本选择。自定义提供商和两个绘画提供商每次新建产生独立草稿；内置提供商从锁定 DSH 的可配置目录选择，使用目录的正式 ID 和默认协议，同一个内置路由已有配置时直接打开它。

内置目录模式使用 pi-ai 的 modelOverrides，仅提交用户更改的上下文、输出和能力声明，其余模型和原生认证方式由目录持有。自定义能力提供文本、图片两个选项，默认只选文本，至少选择一项；内置能力可沿用目录或明确覆盖。压缩、采样和当前请求推理强度继续按模型保存。手动添加的模型可删除，删除其参数并在剩余列表中重选；最后一个模型移除后保留未完成的配置。

新建菜单保留 OpenAI Images 和 NovelAI，继续使用各自的绘画参数与既有调用。配置删除使用带遮罩的确认弹窗，不改变表单布局，只操作指定配置。模型连接测试的界面、Client 服务和 Host Remote 均已移除；模型读取继续由正式适配器执行。

## DSH 0.2.2-rc.1 的请求时机

供应商、模型与思考强度仍可在产品模型配置中修改。角色聊天在发送或重新生成准备时读取当前设置并冻结本轮快照；创作工作室在新一轮的步骤准备时读取。正在执行的轮次保持已经确定的快照，下一轮使用保存后的设置。

在模型和工具集合被捕获之前，通过公开 `agent.model.select` 应用模型选择；`agent/request` 仅继续应用温度、Top P、最大输出等请求参数，不再借此改供应商、模型或思考强度。保持这一时机的受管补丁及退役条件见 `pnpm-workspace.yaml`，它不新增数据库转换或第二套模型设置。

## 验证

真实官方适配器与本地合成 HTTP 服务验证模型发现、凭据隔离和请求参数；页面交互验证模型选中后可编辑、保存重开。Host 冷启动探针同时放入引用已删除预设的快照，验证聊天列表、角色列表及同一 Session 的恢复和模型切换。更新上游时重新核对补丁是否仍需存在。

Google 原生协议回归覆盖四种通信格式的配置保存与恢复，以及模型分页、密钥与请求头、原生正文和思考流、工具调用与鉴权失败；2026-10-14 使用临时凭据实际通过 Google 官方接口的模型发现、工具调用和流式正文请求。未知第三方中转站仍需按其实际接口验收，此记录不代表全部站点已验证。
