# ADR 0041：工具注册来源与预设插件分组

## 决定

预设工具界面按真实插件展示工具集合；外层只显示插件名称与工具数量，插件详情用于查看工具及可用状态。顶部「管理预设工具」按来源选择工具，通过勾选直接加入或移除外层预设草稿中的引用，不另建窗口草稿或「应用修改」确认层。关闭、返回或 Escape 保留草稿，最终写入及放弃改动由外层统一处理；未变更引用保留原有配置，当前管理窗口保留初始工具目录以便重新勾选已移除的缺失引用。查看额外工具不提供加入操作。预设归属与插件来源分别表达，同一插件已有预设引用时，其全部已注册工具集中到同一个插件详情。

锁定的 DSH 0.2.2-rc.1（66491b05e3f05ad35bcdd4f6cd7ed26041d9e3db）公开 `schemas()`、`get()` 及每步 `resolve()`，没有返回注册上下文。Cordis 的 effect 诊断只包含通用标签，不能据此关联工具与插件；不按工具名称、描述或位置猜测来源。

为 `dsh-tools` 增加精确版本补丁：注册记录与工具定义、激活条件一起持有调用 `register()` 的 Context，随同一 disposer 删除；只读 `registrant(name, scope, toolSet?)` 遵循现有可见性、作用域遮蔽、限制及可选的本步激活集合。该上下文仅供 Host 查询，不跨 Remote、不进入模型声明、不保存到数据库。

Host 通过公开 Fiber/Loader entry 与 PluginManager 的 bundle rows 精确关联插件身份和展示名。无法唯一关联 bundle 时保留真实注册模块身份，未声明名称时明确显示来源未声明。保存的预设引用只保留插件的可移植编号和展示名称，缺失插件仍只提醒，不阻止聊天。

## 退役

RETIRE WHEN: 锁定上游公开提供遵循同一工具可见性与作用域规则的注册来源查询。验证全局、作用域遮蔽、限制、卸载和重新注册后，删除 `dsh-tools` 补丁并直接采用该公开查询；界面不再需要额外来源追踪。

## 验证

回归覆盖同名工具的全局与作用域来源、限制后的不可见来源、卸载及重载；产品调用链覆盖一个插件的多项工具、多个插件、混合预设归属、保存导出及缺失插件。界面检查包括深浅主题、桌面与窄屏。
