# ADR 0034：生成图片随记录删除

## 状态

已采纳，2026-10-11。

## 决定

删除聊天、删除角色及回退消息时，从修改前的正式图片状态事件收集自动配图引用；操作成功后，直接删除已不被保留记录或有效输入引用的图片对象。重新生成准备失败时，恢复原日志并保留原图片。使用现有 Session 编辑服务，不新增登记表、启动扫描或后台回收任务。

锁定 DSH 的[本地附件后端](https://github.com/deepseek-ai/deepseek-harness/blob/c1b47e41fcd54d20a0f061df28683bfc29ee24e5/packages/attachment/attachment-local/src/store.ts)没有删除接口。本次采用受限的 Host 文件操作：只删除正式 `imageHostPath()` 对应的本地图片对象，校验对象路径、目录与文件类型，解除只读属性后删除单个文件；拒绝目录越界和对象符号链接。文件删除失败向调用方报错。

PC 和 Android 共用此实现，各自清理本机文件。升级附件后端时重新核对此边界。

自动配图在同一条 AI 文本回复的最终正文边界前输出图片指令，流式捕获完整分镜后启动图片请求，正文继续流式输出，不增加原生工具调用或聊天请求。处理过程从原始回复展示捕获的提示词。图片状态和正式附件引用通过可忽略的 `eleckoi/illustration` Session 插件事件保存；事件不重复保存提示词，单图重画从原始 `assistant/message` 再次解析对应分镜编号。

图片完成后立即发布该批次的新状态，不等待正文或阻塞正文结束；每个 `batchId` 的后续状态明确替换其前一状态。图片任务归当前 Agent 插件作用域，关闭或编辑会话时先取消并等待任务，再交还 Session 写句柄。正文中断时发布失败状态并直接删除无有效引用的已生成对象；有效引用按每批次当前状态计算。渲染层保留生成附件字段，只在流式正文收到对应 `[[IMAGE:n]]` 后显示该图片状态，完成后保持原位置。

单图重画使用现有 Session 关闭与写入锁，在原图片状态事件位置替换指定图片结果，保留正文、事件编号和其他图片；后续消息回退不会撤销更早图片的重画结果。成功替换后立即删除无有效引用的旧对象，失败保留已有图片，保存失败直接删除未进入有效记录的新对象。正文编辑保留其前面的图片指令，图片下载复用各平台现有文件保存入口。

角色会话运行服务在附件、Session 编辑与生图服务就绪后，通过 Cordis 的子作用域 `inject` 装配，读取和单图重画使用该作用域声明的依赖。Session 写句柄服务先由预设桥接提供，避免编辑服务与桥接互相等待。图片读取核对该批次的当前状态与指定图片引用，拒绝读取已被后续状态取消或替换的对象。

## 验收

以实际本地附件存储和 Session 持久化测试聊天删除、角色删除、重新生成、准备失败回滚、有效输入保留及路径越界拒绝。成功操作结束时即检查原文件已经消失。

## 自动配图插件边界（2026-11-01）

自动配图由独立 bundle `@eleckoi/dsh-auto-illustration` 持有生图队列、请求提示词、回复流捕获和重画。该插件通过官方插件页的 `plugins.bundle.config` 配置每个角色预设的启用状态和图片模型；不注册 AI 工具，不列入预设工具组。插件配置页的选择独立保存，不经过预设工具弹窗的草稿。

角色会话只在插件服务存在时取得本轮配图指令；插件停用不影响角色会话服务装配和正常聊天。原图片事件、附件读取和投影仍由角色会话保留，历史图片不依赖自动配图插件启用；停用后重画明确提示启用插件。

旧配置的转换、导入边界和可核验退役条件见[角色自动配图](../plugins/auto-illustration.md)。
