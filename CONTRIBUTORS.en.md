# ElecKoi Contributor Record

ElecKoi is grateful to everyone who contributes through code, architecture design, documentation, testing, visual design, creative practice, and public discussion. This file records special contributions whose scope can be described clearly; code contributions reflected in commits and pull requests remain documented by the GitHub history.

## CoreForgeLab — Architecture & Database Design

[GitHub: @CoreForgeLab](https://github.com/CoreForgeLab)

CoreForgeLab's contributions currently focus on project architecture and database design. This work includes analyzing and auditing the existing storage architecture and data lifecycles; clarifying relationships and permission boundaries among Characters, dynamic character state, chats, group chats, and Agents; and proposing long-term database and persistence refactoring directions. Topics include separating Character Cards from Character Instances, strong isolation between multiple instances and Agents, Multi-Agent relationships in group chats, dual indexing by resource ID and path, the division of responsibilities between Markdown and JSON, and deletion recovery and backup strategies.

CoreForgeLab has also contributed to organizing related design documents, Issues, public discussions, and plans for future evolution. This record acknowledges contributions to architecture auditing, design, and planning; it does not imply that every discussed proposal has already been implemented or finalized. Concrete implementation will continue to evolve through future project discussion and development.

## Recording Principles

- Contributors retain copyright in their code, designs, documentation, and other original works; the applicable license is determined by the relevant file, contribution, and project license.
- This file describes only contribution scopes that can be confirmed clearly. A listing here does not replace the factual record in Git history, pull requests, Issues, or design documents.
- Designs that remain under discussion are identified as planning contributions rather than completed implementation, so proposals are not presented as established facts.
