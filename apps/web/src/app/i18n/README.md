# ElecKoi 界面语言

`ProductLocaleProvider` 只把官方 `LocaleRuntime` 接入产品 React 树，拥有 `eleckoi.ui` 词典命名空间。语言选择、通知、回退及保存继续由官方服务和 `locale.preference` 管理；这里没有第二份语言偏好，也不通过重建页面或替换 DOM 文字实现翻译。

产品页面使用 `useProductTranslation()`，以中文原文作为词典键，动态内容通过具名参数插入。新增或修改文案时同步维护中文、英语、日语、西班牙语、法语、德语、俄语和巴西葡萄牙语八份资源。原文作为键是长期的文案约定，与旧版本迁移无关。

`localizeUiCopy` 只用于源码声明的界面选项和说明表。角色、预设、模型配置、文件路径和作者内容不能整体传入。纯展示辅助函数接受翻译函数参数，默认的原文函数保留无客户端环境的确定性；例如错误文档生成器仍读取同一张错误码文案表。错误码、详情和诊断保留原值，翻译在显示时完成。

日期格式从同一个官方语言状态获取区域标记。语言切换通过订阅刷新文字与选项缓存，不改变组件身份、输入草稿或当前 Session。设置入口位于「聊天显示」列表末尾，使用既有分组卡片与翻译图标，内部仍渲染官方语言控件。

与 DSH 相同的文案复用锁定 `0.2.2-rc.1`、提交 `66491b05e3f05ad35bcdd4f6cd7ed26041d9e3db` 的语言资源。产品轨迹命名空间的新增六语言优先采用该版本官方轨迹翻译；产品专属字段单独补齐。

回归入口：`apps/web/tests/ui/product-locale.test.jsx`。它使用实际安装的官方 `LocaleRuntime`，核对八语言显示、参数完整性、输入与焦点保留、错误证据和自定义名称保留。
