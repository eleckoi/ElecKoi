# 角色自动配图

`@eleckoi/dsh-auto-illustration` 是独立功能插件，通过角色回复中的分镜文本指令调用 NovelAI 图片接口，不向 Agent 注册 AI 工具。插件随应用提供，默认关闭，新建、升级及恢复默认启动组合都不会自动启用，须由用户在插件页手动开启；启用后在插件详情页配置，不出现在「管理预设工具」或聊天工具列表。

## 配置与运行

插件详情提供预设选择、该预设的自动配图开关，以及原有的图片模型与参数选择。开关直接保存；模型选择器的保存是该独立操作的唯一提交入口。每个预设保留各自的模型绑定，模型密钥仍由现有模型与 Credentials 服务管理。

预设领域使用 `autoIllustration: { enabled, modelConfigId }` 保存公开配置；导出的 JSON/PNG 在 `plugin_configuration` 下以插件包名记录相同选择，不携带插件代码或模型密钥。导入、版本恢复及复制保留该配置。未启用插件时，这份配置不注入提示词、不启动生图，也不阻止正常聊天。

Host 通过官方 Cordis 服务 `eleckoiAutoIllustration` 向角色会话贡献本轮指令与重画能力，流式捕获只处理具备角色会话配置的根 Session。每个后台图片任务通过对应 Agent 的 Cordis effect 绑定到所属会话，关闭会话先取消并等待任务；任务完成后立即释放绑定。插件卸载取消并等待自己的全部图片任务、关闭队列和释放监听。图片事件格式与正式附件引用保持不变，角色会话继续负责历史图片的投影与授权读取，因此关闭插件后历史图片仍可查看。

## 旧配置转换

没有数据库表结构变更。`AgentPresetRepository` 初始化在一个写事务中将当前与历史版本的配置 JSON v4/v5 转成 v6：保留自动配图的模型绑定及启用状态，移除旧 `builtin:auto-illustration` 工具编号，并写入独立的 `autoIllustration` 配置。旧导出文件只在导入边界做同样转换；正常运行只读取当前字段。

旧 profile 在桌面 bundles-v9 登记时保留已有插件的启停选择和用户补丁，不自动加入自动配图插件；正常启动也不会重新打开用户已停用的插件。原预设的配图开关和模型绑定只转换为配置，不用于推断或更改插件启用状态。已保存的 Session 预设恢复时过滤被替代的 `image-generation-tools` 内部挂载，避免再次执行旧处理器。

这些转换均在对应实现旁有 `RETIRE WHEN:`：停止支持旧预设配置与导入文件后，连同 v4/v5 转换一起清理；所有受支持 profile 完成 v9 登记后清理启动登记；所有受支持 Session 预设完成重新生成后清理旧处理器过滤。历史图片格式不是过渡兼容层，继续作为正式读取合同维护。
